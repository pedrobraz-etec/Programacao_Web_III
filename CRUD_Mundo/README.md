# CRUD Mundo

Nome do(a) aluno(a): ______________________________

## Tecnologias
HTML5, CSS3, JavaScript, PHP, MySQL e Git/GitHub.

## Descrição
Sistema web para gerenciamento de continentes, países, cidades e governantes, com operações CRUD, relacionamentos, validações, confirmação de exclusão e pesquisa dinâmica.

## Instalação
1. Instale o XAMPP.
2. Inicie Apache e MySQL.
3. Coloque a pasta `CRUD_Mundo` dentro de `htdocs`.
4. Abra o phpMyAdmin.
5. Importe `bd_mundo.sql`.
6. Acesse `http://localhost/CRUD_Mundo/`.
